## Repository summary (longer, for project board or sharing)
Merge Packs is a new one-round instant-game concept inspired by a card-merging interaction. A single bet opens a six-card pack. Matching colored cards merge into higher values while an Extra Pack card can open additional packs within the same paid round. The board persists across the chain. A Skull ends the entire run at 0× and erases the potential payout. If no Skull occurs, the round pays once after the final pack. v0.1 is demo-only with provisional math and no real-money integration.
